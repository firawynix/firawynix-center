# Third-party notices

Firawynix Center depends on open-source packages from the Rust and npm
ecosystems. Their exact versions are recorded in `Cargo.lock` and
`package-lock.json`.

Major components include React, Tauri, Tokio, Reqwest, Serde, and related
transitive dependencies. Each component remains subject to its own license.
Run an automated dependency-license report for every public release and retain
the result with the build provenance.
