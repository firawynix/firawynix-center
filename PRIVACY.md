# Privacy policy

Firawynix Center doesn't collect analytics, account information, telemetry, or
personal data.

The application contacts its configured catalog API to retrieve public catalog
entries and update information. It contacts download addresses only when the
user requests an installation or update. The selected catalog may point to
third-party websites whose own privacy policies apply.

The application stores the last valid catalog, installation state, and user
preferences locally on the user's computer. It doesn't transmit that local
state to Firawynix.

Build tools may contact npm, crates.io, GitHub, and operating-system package
repositories while maintainers or contributors compile the project. This
build-time activity isn't part of the installed application's behavior.

Report privacy concerns through the public issue tracker without including
sensitive information. Use GitHub private vulnerability reporting for security
issues.
